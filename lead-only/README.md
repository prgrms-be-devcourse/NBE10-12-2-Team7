# 팀장 전용 — PR 리뷰 · 통합 도구

이 폴더는 팀장만 보유한다. 팀원 배포 폴더(`docs/`)와 겹치지 않게 분리되어 있다.

- `06-integration-agent.md` — PR이 올라올 때마다 에이전트에 연결해 1건씩 검수·통합 판정에 사용.
- `99-ai-review-checklist.md` — 06이 PR을 검수할 때 기준으로 삼는 체크리스트.

## 사용법

1. 팀원의 PR이 올라온다.
2. 에이전트에 `06-integration-agent.md`를 읽히고, 그 PR의 변경 파일·diff를 입력한다.
3. 06이 99 체크리스트 기준으로 검수 → 통과/보류 판정.
4. 통과면 팀장이 develop에 머지, 보류면 사유와 함께 작성자에게 반려.
5. 17:00~18:00에 develop 전체를 한 번 더 검증해 최종 통합 상태를 확정한다.
