# 팀장 전용 — PR 리뷰 · 통합 도구

이 폴더는 팀장만 보유한다. 팀원 배포 폴더(`docs/`)와 겹치지 않게 분리되어 있다.

- `06-integration-agent.md` — PR마다 1건씩 **검수 → 합병 → 기능 설명** 흐름으로 통합 판정·설명에 사용.
- `07-daily-pr-summary.md` — 하루 마무리에 그날 PR을 모아 요약하는 **일일 집계**(읽기 전용·채팅 출력).
- `99-ai-review-checklist.md` — 06이 PR을 검수할 때 기준으로 삼는 체크리스트.

## 사용법 (검수 → 합병 → 기능 설명 → 일일 요약 순)

1. 팀원의 PR이 올라오면, 팀장이 **PR 번호**를 06 에이전트에 준다.
2. **검수 (머지 전)** — 06이 `gh pr diff`로 코드를 수집해 99 체크리스트로 검수하고, 『검수 리포트』(통과/조건부 통과/보류 판정)를 **빠르게** 출력한다. *(설명을 먼저 하면 작성자가 판정을 오래 기다리므로 검수를 먼저)*
3. **합병** — 팀장이 판정을 보고 develop에 머지(또는 사유와 함께 반려)한다. **머지는 사람이 한다.**
4. **기능 설명 (머지 후)** — 06이 머지된 기능을 다이어그램 + 코드로 팀장에게 설명한다(explain 방식, 채팅에서 종료).
5. **일일 요약 (마무리)** — 하루 정리 시간(17:00~18:00)에 팀장이 호출하면 07이 그날 PR을 `gh`로 모아 요약 리포트를 채팅에 낸다(읽기 전용 집계, 머지·저장 없음).

> 검수~설명은 06, 일일 요약은 07로 끝난다. 노션 역할 리포트·LLM 위키는 복잡도 때문에 도입하지 않는다(보류).
