## 무엇을 / 왜

상품 목록(메인) 페이지에 내 동네 설정 버튼이 구현되어 있지 않은 것을 확인하고,
이 기회에 페이지 전체를 디자인 시안에 맞춰 리디자인했다.
헤더의 알림 버튼 추가, 채팅 버튼 위치 조정도 함께 진행했다.

## 어떻게 (구현 요약)

- [x] 활동 배너(그라데이션 + 이웃/매물/거래 수 카운트업 애니메이션) 추가 — 실제 집계 API가 없어 디자인 시안의 예시 수치를
애니메이션에만 사용
- [x] 내 동네 설정 버튼 + 모달 추가: 내 동네 조회/추가/삭제 API 연동, 최대 2개 제한, 선택한 동네로 상품 목록 실시간 필터링
(계정 대표 동네 설정과는 별개로 세션 내 보기 필터로 동작)
- [x] 검색바를 동네 버튼과 한 줄로 통합, 카테고리 칩·피드 헤더·상품 카드 UI를 디자인 시안대로 재구성
- [x] 상품 카드에 찜 버튼 추가 — 실제 관심상품 API와 연동, 카드 클릭(상세 이동)과 분리 처리
- [x] 배지 색상 확정: 판매중(빨강)·예약중(파랑)·나눔(초록)·거래완료(회색), 다크모드에서도 동일한 색상 유지
- [x] 헤더: 알림 벨 버튼 추가(외형만, 실제 알림 기능 없음), 채팅 버튼을 텍스트 메뉴 → 우측 아이콘 버튼 줄로 이동
(테마 전환 → 알림 → 채팅 → 로그인 순)
- [x] 헤더 컨테이너 너비를 상품 목록 배너와 동일하게 맞춰 좌측 정렬 일치
- [x] 활동 배너 그라데이션을 좌우로 오가는 애니메이션으로 변경, 활성 표시 점에 깜빡임 효과 추가

**검증**

프론트엔드 전용 작업이며 대상 API는 이미 검증된 기존 API이다.
로컬 백엔드를 직접 실행해 실제 데이터로 동네 설정 모달, 지역 필터, 찜 버튼, 검색을 라이브로 확인했다.
추가로 `tsc --noEmit`, `npm run build` 통과를 확인했다.
