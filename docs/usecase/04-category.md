# UC-014. 카테고리 목록 조회

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 유즈케이스 ID | UC-014 |
| 유즈케이스명 | 카테고리 목록 조회 |
| Actor | 비회원 (Guest) |
| 목적 | 전체 카테고리를 정렬된 순서로 조회한다 |
| 사전 조건 | 없음 (공개) |
| 성공 결과 | 카테고리 목록(id 오름차순) |
| 실패 결과 | — |
| 우선순위 | Low |
| 담당자 | 한상민 |

## 2. 기본 흐름

1. 사용자가 카테고리 목록을 요청한다.
2. 시스템이 카테고리를 id 오름차순으로 조회한다.
3. 목록을 반환한다(200).

## 3. 예외 흐름

| 번호 | 예외 상황 | 시스템 처리 |
| --- | --- | --- |
| E-001 | 카테고리 없음 | 빈 리스트 |

## 4. 비즈니스 규칙

- 카테고리는 시스템(Initializer)이 시드하며 사용자 생성 경로 없음.
- 정렬은 id 오름차순(고정 순서).

# UC-015. 카테고리별 상품 조회

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 유즈케이스 ID | UC-015 |
| 유즈케이스명 | 카테고리별 상품 조회 |
| Actor | 비회원 (Guest) |
| 목적 | 특정 카테고리의 판매중 상품을 조회한다 |
| 사전 조건 | 카테고리 존재 |
| 성공 결과 | 해당 카테고리 상품(삭제·숨김 제외, id DESC) |
| 실패 결과 | 카테고리 없음 시 거부 |
| 우선순위 | Medium |
| 담당자 | 한상민 |

## 2. 기본 흐름

1. 사용자가 categoryId로 상품 목록을 요청한다.
2. 시스템이 카테고리 존재를 확인한다.
3. 해당 카테고리의 미삭제·미숨김 상품을 id DESC로 조회한다.
4. 목록을 반환한다(200).

## 3. 예외 흐름

| 번호 | 예외 상황 | 시스템 처리 |
| --- | --- | --- |
| E-001 | 존재하지 않는 카테고리 | 404 `CATEGORY_NOT_FOUND` |
| E-002 | 상품 없는 카테고리 | 빈 리스트 |

## 4. 비즈니스 규칙

- 카테고리 미존재는 빈 리스트가 아니라 명시적 404 오류.
- 삭제·숨김 상품 제외, id 내림차순(UC-007과 동일 필터).

## 5. 필요한 데이터 후보

| 데이터 | 설명 |
| --- | --- |
| categoryId | 대상 카테고리 |

| --- | --- |
| (없음) | 조회 전용 |
